# 🐷 Chuồng Heo Vui Vẻ

Game nông trại nuôi heo 2.5D dành cho cặp đôi & bạn bè, tối ưu riêng cho **iPhone (màn hình dọc & ngang)**, không cần cài server riêng.

## 🚀 Cách đưa lên GitHub để gửi link cho người yêu chơi ngay

1. Đẩy toàn bộ code trong thư mục này lên repository GitHub của bạn (nhánh `main` hoặc `master`).
2. Trên GitHub, vào **Settings → Pages**:
   - Mục **Source**: chọn **GitHub Actions**.
3. Chờ khoảng 1 phút để Action **Deploy Chuong Heo Vui Ve to GitHub Pages** chạy xong (dấu tích xanh ✅).
4. Mở link dạng `https://<tên-github>.github.io/<tên-repo>/` trên iPhone của bạn.
5. Trong game, bấm nút **Cặp Đôi 💕 → Gửi Link Cho Người Yêu** (hoặc đưa mã QR cho máy kia quét bằng Camera).
   - Người yêu bấm vào link là **vào thẳng game, tự nhận mã phòng chung và đồng bộ chuồng heo ngay lập tức** — không cần cài app hay copy mã thủ công.

## 💻 Chạy thử trên máy

```bash
npm install
npm run dev
```

## 📦 Build bản tĩnh (Single-file)

```bash
npm run build
```
